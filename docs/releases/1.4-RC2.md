# NeonPocketMC suite v1.4.0 RC2

Suite 1.4 RC2 pins the corrected Ultimate Companion release without duplicating product-owned firmware binaries.

## RCC6 products

- Ultimate Companion `v2.3.0-rc.2`: separate BLE and authenticated Web images, signed Web OTA, human-first traffic and signal analytics, coordinate-backed nearby-node mapping, and a truthful on-device MeshCore 1.17.0 + RX-fix version label.
- Ultimate Observer & Room Server `v1.3.0-rc.1`: MQTT observer plus four Room Server profiles, responsive service dashboard, traffic and broker-health bars, and honest nearby-radio mapping.

## Suite assets

- `catalog.json` records every product release URL, exact source commit, install filename, size, and SHA-256 digest.
- `SHA256SUMS.txt` authenticates the catalog itself.
- Firmware remains owned by the linked product releases so one public binary has one canonical download.

Every RCC6 release uses official MeshCore 1.17.0 plus the post-release SX126x boosted-RX-gain persistence fix. No official upstream 1.17.1 tag existed when these candidates were published.
