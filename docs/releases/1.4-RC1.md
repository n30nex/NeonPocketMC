# NeonPocketMC suite v1.4.0 RC1

Suite 1.4 pins the latest published NeonPocketMC product releases without duplicating their firmware binaries.

## Updated RCC6 products

- Ultimate Companion `v2.3.0-rc.1`: separate BLE and authenticated Web images, signed Web OTA, plain-language Overview/Messages/Nearby/Radio/Device navigation, traffic and signal analytics, and coordinate-backed nearby-node mapping.
- Ultimate Observer & Room Server `v1.3.0-rc.1`: MQTT observer plus four Room Server profiles, responsive service dashboard, traffic and broker-health bars, honest nearby-radio mapping, and reviewed MQTT memory/reconnect/path-validation fixes.

## Suite assets

- `catalog.json` records every product release URL, exact source commit, install filename, size, and SHA-256 digest.
- `SHA256SUMS.txt` authenticates the catalog itself.
- Firmware remains owned by the linked product releases so one public binary has one canonical download.

Every RCC6 release uses official MeshCore 1.17.0 plus the post-release SX126x boosted-RX-gain persistence fix. No official upstream 1.17.1 tag existed when these candidates were published.
