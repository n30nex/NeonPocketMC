# NeonPocketMC suite v1.7.0 RC1

Suite 1.7 RC1 adds a dedicated screenless RC52 BLE companion without duplicating product-owned firmware binaries.

## RC52 headless companion

- Hardware: Heltec RadioCore RC52-L62/SX1262 without the NV3001B TFT.
- Transport: standard MeshCore BLE companion protocol.
- Default pairing PIN: `123456`.
- Normal installation: copy the application-only UF2 to the RC52 bootloader drive.
- The UF2 starts at `0x26000` and preserves the bootloader, SoftDevice, MeshCore identity, contacts, channels, and preferences.

The TFT RC52 companion remains a separate build and repository. Do not flash the screenless image when the local NeonPocket display interface is required.

## Suite assets

- `catalog.json` records every product release URL, exact source commit, install filename, size, and SHA-256 digest.
- `SHA256SUMS.txt` authenticates the catalog and exact suite source bundle.
- Product repositories remain the single owners of firmware binaries and setup packages.
