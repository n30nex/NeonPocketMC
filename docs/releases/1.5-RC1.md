# NeonPocketMC suite v1.5.0 RC1

Suite 1.5 RC1 adds first-class native-USB companion choices without duplicating product-owned firmware binaries.

## Companion transports

- Heltec V3 `v1.0.0-rc.3`: separate BLE and native-USB companion images.
- Heltec V4/V4.3 `v1.0.0-rc.3`: separate BLE and native-USB companion images.
- RC52 `v1.1.0-rc.4`: separate application-only BLE and native-USB UF2 images.
- RCC6 Ultimate `v2.3.0-rc.3`: separate BLE, native-USB, and authenticated Web images.

The native-USB images expose the standard binary MeshCore companion protocol. They are not text-CLI firmware, and no image runs BLE, USB, and Wi-Fi simultaneously.

## Guided flasher

The new Pi-hosted [NeonPocketMC Flasher](https://flasher.canadaverse.org/) selects exact hardware and role, verifies release hashes, flashes without a whole-chip erase, checks restart health, and guides supported server onboarding. Firmware remains canonically hosted by each product's GitHub release.

## Suite assets

- `catalog.json` records every product release URL, exact source commit, install filename, size, and SHA-256 digest.
- `SHA256SUMS.txt` authenticates the catalog itself.
- Product repositories remain the single owners of firmware binaries and setup packages.
