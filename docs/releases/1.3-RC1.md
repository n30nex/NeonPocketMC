# NeonPocketMC suite v1.3.0 RC1

This catalog-only prerelease pins the current product-owned firmware releases. It does not duplicate their binaries.

## Updated products

- RCC6 Ultimate Companion `v2.2.0-rc.1`: separate BLE and authenticated Web images, signed Web OTA package, Ultimate on-device experience, and persisted battery-size calibration support.
- RCC6 Ultimate Observer/Room Server `v1.2.0-rc.1`: observer plus minimal/full, headless/TFT profiles, shared configurator, and live service dashboards.
- RC52 companion `v1.1.0-rc.3`: triple press returns Home; in Inbox it clears local unread state first.
- Heltec V3 and V4 companions `v1.0.0-rc.2`: the same triple-press Home/unread shortcut on board-correct OLED builds.

Every installable filename, byte count, SHA-256 digest, public release URL, and exact source commit is recorded in `catalog.json`. Download firmware only from its owning product release.
