# NeonPocketMC Suite v1.10.0 RC2

This catalog hotfix makes LAN WebUI credentials visible and unambiguous for every affected Wi-Fi companion:

- Heltec V3 Ultimate Web `v2.0.0-rc.2`
- Heltec V4 Ultimate Web `v2.0.0-rc.2`
- RCC6 Ultimate Web `v2.3.0-rc.7`
- RCC6 Headless Web `v1.0.0-rc.5`

After Wi-Fi setup, sign in with username `meshcore` and the eight-letter device key shown before restart. The device key is not the router password. It is also printed over USB serial; V3/V4 and screen-equipped RCC6 builds show it on-device.

Only the affected Web images moved. Existing BLE, native-USB, repeater, Room Server, and signed RCC6 OTA artifacts remain pinned to their previous verified releases. All firmware was built and verified locally on the Canadaverse Pi 5; this release did not use GitHub Actions.
