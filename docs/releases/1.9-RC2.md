# NeonPocketMC Suite v1.9.0 RC2

This catalog-only hotfix pins the three RCC6 releases that make saved-location advertising explicit:

- RCC6 Ultimate Companion `v2.3.0-rc.5`
- RCC6 Headless Companion `v1.0.0-rc.3`
- RCC6 Ultimate Observer and Room Server `v1.3.0-rc.3`

Web location controls show whether saved coordinates will be included in MeshCore adverts. The current safety refresh also rejects impossible RCC6 single-cell ADC readings, renders the unavailable state honestly, preserves chart time slots, and suppresses invalid battery telemetry.

The RC52, Heltec V3/V4, and ULP families are unchanged because they do not expose this misleading RCC6 Web location flow.
