# NeonPocketMC Suite v1.9.0 RC2

This catalog-only hotfix pins the three RCC6 releases that make saved-location advertising explicit:

- RCC6 Ultimate Companion `v2.3.0-rc.4`
- RCC6 Headless Companion `v1.0.0-rc.2`
- RCC6 Ultimate Observer and Room Server `v1.3.0-rc.2`

Web location controls now show whether saved coordinates will be included in MeshCore adverts. Existing nodes are not silently opted in: the user must select the sharing policy.

The RC52, Heltec V3/V4, and ULP families are unchanged because they do not expose this misleading RCC6 Web location flow.
