# Heltec V4 live OLED captures

These files were exported from the 128x64 SSD1306 framebuffer of the physical Heltec WiFi LoRa 32 V4 qualification unit. They are device-rendered frames, not reconstructed mockups.

- Production source base: `92fb0a5290f685f5f4c7b3b60e11ccbf9f40c1f5`
- Hardware: Heltec WiFi LoRa 32 V4/V4.3 with integrated OLED and SX1262/FEM radio path
- Capture: temporary app-only diagnostic build; MeshCore SPIFFS identity partition was backed up and left untouched
- The capture hook is absent from the released BLE image
