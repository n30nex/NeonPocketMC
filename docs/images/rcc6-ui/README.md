These PNGs were exported directly from the live 220×128 RGB565 framebuffer of the connected Heltec RCC6 test unit on 2026-08-09. They are not reconstructed browser mockups.

- Temporary capture commit: `977f4e4ed4e392a79d36c229e5bd7a25cec0bef5`
- GitHub Actions run: [`31336975633`](https://github.com/n30nex/NeonPocketMC-RCC6/actions/runs/31336975633)
- Diagnostic app SHA-256: `fbbd958340c4950b9c7ff22bf46975479fe21aab0c10d94804552eb92d2276f2`
