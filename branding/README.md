# NeonPocketMC brand mark

`neonpocketmc-mark.png` is the canonical transparent 1024 x 1024 project mark. GitHub pages may scale this file directly; firmware should use a target-specific indexed or RGB565 derivative generated from this master.

The mark combines a pocket, a three-node mesh, and outgoing packet sparks. Its palette matches the NeonPocket interface:

- electric cyan: `#20D9ED`
- cobalt: `#1E5AEF`
- neon lime: `#84FF2E`
- charcoal: `#17191A`

Keep clear space around the mark and do not add a box, glow, gradient, or device name inside it. Product names belong beside or below the mark so the same symbol works across RC52 and RCC6 roles.

## Generation provenance

The raster master was created with OpenAI image generation in logo/brand mode, then the flat magenta key background was removed and alpha-validated. The final prompt requested a compact flat vector-style pocket outline containing a three-node mesh constellation with outgoing packet sparks, using charcoal, cyan, cobalt, and lime, with no text, gradients, glow, or resemblance to Wi-Fi, Bluetooth, Apple, Android, or Meshtastic marks.
